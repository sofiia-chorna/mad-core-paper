`sofiia-chorna/mad-core-paper`, branch `develop`, no commits yet). Sources: papers repo
`paper/` at 28cfe43, dev repo `phace-atomic/` at 97bec6f, aa002 store (`store:` =
`/capstor/store/cscs/swissai/aa002/mad-core/`). A machine-readable list with byte sizes and
SHA-256 of every proposed file is in `inclusion_list.tsv` (generated by
`evidence/build_inclusion_list.sh`). Sizes below are rounded; `inclusion_list.tsv` (byte sizes and SHA-256 per file, 472 lines, generated on 2026-10-16) is authoritative. Repo tiers total 97.4 MB; the data-archive tier 4.49 GB.

Three tiers: **repo** (in the git repository and the frozen source archive), **data archive**
(supporting results too large for the repo but needed for L1/L2), **external** (referenced,
not copied). "orig" marks original analysis code copied with attribution; "new" marks code to
be written in stage 2 (reconstruction, wrappers, checks).
