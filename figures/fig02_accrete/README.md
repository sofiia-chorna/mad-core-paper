# Fig. 2, the accretion scheme

`reference_figures/submitted/accrete.pdf` is a hand-drawn conceptual illustration of the
accretion algorithm. No editable source (svg, drawio, keynote) exists in either source
repository or their git histories, so there is nothing to regenerate. The palette of the
drawing is recorded as `ACCRETE` in `plotting/epfl.py`, where it was recovered from the fill
operators of the PDF and reused by the other figures.
